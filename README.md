# 高性价比人生指南 · 手机网页版

这是《高性价比人生指南》的**手机网页版**，与微信小程序版内容一致（669 条、34 章）。

## 怎么用

- 手机浏览器打开首页即可，无需下载、无需登录
- iPhone：用 **Safari** 打开 → 点分享按钮 → 「添加到主屏幕」，之后像 App 一样全屏打开
- Android：用 Chrome / 夸克 等浏览器打开 → 菜单 → 「添加到主屏幕」

## 你的数据存在哪

收藏、阅读历史、昵称头像全部保存在**你自己手机的浏览器本地**（localStorage），
不上传、不联网、没有账号。换手机或清除浏览器数据会丢失，可在「我的 → 导出收藏」备份为文本。

## 目录结构

```
index.html      入口页
app.css样式
app.js          全部逻辑（hash 路由单页应用）
manifest.json   PWA 配置（添加到主屏幕用）
icon.svg        图标
data/index.json 索引（159KB，首屏加载）
data/ch-01.json ~ ch-34.json 分章正文（按需加载）
```

首屏只需约 202KB，打开很快；点进某一章才加载对应的那一个 JSON。
